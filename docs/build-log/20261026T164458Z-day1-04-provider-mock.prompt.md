RULES
- The app may call ONLY Meta models at runtime. Allowed model ids: "muse-spark-1.3" and
  "muse-wonder-1.0". Reject any other id with a clear error. Never switch model or provider silently.
- Runtime config comes from environment variables ONLY: ARIA_HOME_PROVIDER_URL, ARIA_HOME_MODEL_ID,
  MODEL_API_KEY, ARIA_HOME_MODEL_ENABLED (default-off: live calls happen only when it is exactly
  "1"). Never read META_CLAUDE_CODE_KEY or any ANTHROPIC_* variable. Never log or return the key
  or request headers.
- Endpoint shape is NOT yet verified from official docs. Implement the request for an
  Anthropic-Messages-compatible API (POST {base}/v1/messages, header "Authorization: Bearer <key>",
  JSON body with model, max_tokens, messages) and mark it in a module docstring as
  "UNVERIFIED: confirm against Meta's official docs before the first live call". Keep the request
  builder in one small function so it is easy to change.

BUILD backend/aria_home/provider.py
- `ProviderResult` (pydantic): ok, mode ("mock" | "live"), requested_model, answered_model,
  text (str | None), latency_ms, input_tokens, output_tokens (None when not returned), error
  (category string or None: not_configured | disabled | timeout | auth | rate_limited |
  server_error | bad_response | model_mismatch).
- `MockProvider`: deterministic canned reply; result.mode is ALWAYS "mock" and the text starts with
  "[MOCK - not live inference]".
- `MetaProvider(config, transport=None)`: httpx client with configurable timeout (default 20 s),
  max output tokens (default 256) and retries fixed at 0. Missing key -> error not_configured with
  zero network calls. ARIA_HOME_MODEL_ENABLED != "1" -> error disabled with zero network calls.
  Map 401/403 -> auth, 429 -> rate_limited, 5xx -> server_error, unparseable body -> bad_response.
  If the answered model differs from the requested one -> ok=False, error model_mismatch (never
  accepted silently).
- `get_provider(env)` returns MockProvider unless live is enabled and configured.
- Add `GET /api/provider` to app.py: returns mode (mock/live), configured model id, enabled flag,
  and whether a key is present as a boolean only. Never the key.
